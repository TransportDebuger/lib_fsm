# Changelog

Все значимые изменения проекта описываются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/),
и этот проект придерживается [Semantic Versioning](https://semver.org/).

## [1.0.3] - 2026-10-22

### Added
- Код ошибки `S21_FSM_CAPACITY_OVERFLOW` для индикации переполнения `size_t` при расчёте ёмкости массивов (Task ID: FSM-105).
- Добавлены unit-тесты, покрывающие механизм graceful degradation (fallback) при нехватке памяти (Task ID: FSM-105).

### Changed
- Стратегия роста массивов состояний и переходов: вместо фиксированного шага применён геометрический рост (x1.5) с резервной попыткой линейного роста при неудачной аллокации (Task ID: FSM-105).

### Fixed
- Устранён риск переполнения `size_t` при вычислении размера блока для `realloc` (CERT MEM04-C) (Task ID: FSM-105).
- Устранено опасное сужение типов `size_t` к `int` во внутренних функциях поиска индексов (CERT INT31-C / MISRA) (Task ID: FSM-106).

## [1.0.2] - 2026-07-08

### Fixed
- Устранена ошибка реэнтрантности при инициализации FSM (`s21_fsm_initialize()`) (Task ID: FSM-101).
- Устранена ошибка реэнтрантности при сбросе FSM (`s21_fsm_reset()`) (Task ID: FSM-102).

### Changed
- Добавлена `const`-корректность в сигнатуры функций-геттеров (`s21_fsm_get_context`, `s21_fsm_get_state_context`, `s21_fsm_get_transition_context_exact`) (Task ID: FSM-103).

## [1.0.1] - 2026-07-03

### Fixed
- Устранено нарушение защиты от реэнтрантности при инициализации машины состояний (`s21_fsm_initialize()`) (Task ID: FSM-101).

## [1.0.0] - 2026-06-27

### Added
- Первоначальный релиз библиотеки s21 FSM Library.
