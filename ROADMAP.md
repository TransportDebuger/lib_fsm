# Roadmap

## [1.1.0] - Planned
### Added
- [FSM-109] Инъекция кастомного аллокатора (s21_fsm_allocator_t).
- Расширение API: функция s21_fsm_create_ex().

### Changed
- Внутренняя структура struct s21_fsm (добавление указателя на аллокатор).

## [2.0.0] - Planned
### Changed
- [FSM-107] Переход на хеш-таблицы для хранения состояний и переходов (O(1) поиск).
- [FSM-108] Внедрение shrink-аллокации для динамических массивов.

### Breaking
- Изменение ABI из-за модификации внутренних структур.
