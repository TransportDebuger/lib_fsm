# Roadmap

## [1.1.0] - Planned
### Added
- [FSM-107] Error Context: расширенный контекст ошибок (POD-структура + copy-out)
- [FSM-108] Инварианты графа: атомарная замена initial/current state при удалении
- [FSM-109] Latched state: детекция неконсистентности графа + блокировка
- [FSM-110] Recovery: latch hook + явная функция восстановления

## [1.2.0] - Planned
### Added
- [FSM-111] Injectable allocator (`s21_fsm_create_ex`)
### Changed
- [FSM-112] Shrink-аллокация для динамических массивов
- [FSM-113] Ускорение поиска (отсортированные массивы + бинарный поиск)

## [2.0.0] - Planned
### Breaking
- [FSM-201] Модель владения и потокобезопасность
- [FSM-202] Хеш-индекс для состояний/переходов (изменение контракта обхода)
